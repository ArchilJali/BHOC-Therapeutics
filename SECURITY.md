# Security policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Report it privately to `info@bhoctherapeutics.com` with the affected URL, reproduction steps, impact, and any supporting evidence.

Do not include patient data, credentials, access tokens, personal contact data, or other sensitive material in the report. We will acknowledge receipt and coordinate remediation and disclosure as appropriate.

## Supported version

Security fixes apply to the current production branch and the live site. Older commits and archived previews are not supported deployments.
